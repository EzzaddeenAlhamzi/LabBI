# LabBI Visual Identity

## Brand

- **Name**: LabBI — Laboratory Information & Business Intelligence
- **Mark**: Original SVG laboratory flask/test-tube motif — a rounded flask outline containing a bubbling column and baseline, rendered in white on a teal gradient tile (`#0D9488 → #0F766E`).
- **Variations**: full lockup (sidebar, 40px tile + wordmark + subtitle), compact icon (favicon data-URI, collapsed rail, login page 56–60px tile).
- **Wordmark**: "LabBI" in Cairo 800; subtitle "Laboratory Information & BI" in muted blue-gray.

## Palette rationale

Deep navy (`#142B45`) conveys clinical authority and anchors the dark sidebar; medical teal (`#0D9488`) is the single primary action/accent color; analytics accents (blue/purple/cyan) are reserved for data visualization. Status colors follow clinical semantics (green=normal/complete, amber=pending, red=critical/danger) and are always paired with text labels + icons — never color alone.

## Style principles applied

- Light theme: `#F5F7FB` app background, white cards, 1px `#E2E8F0` borders, soft navy-tinted shadows
- Minimal, dense-but-breathable enterprise layout; 8px spacing grid
- Restrained 150–200ms transitions; no decorative gradients on content, no 3D charts, no emoji icons
- RTL-first (Arabic), logical CSS properties used for directional safety
